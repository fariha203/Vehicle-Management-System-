# Vehicle Management System

This is a simple Vehicle Management System developed using C.

## Features
- Add new vehicle
- Show all vehicles
- Search vehicle
- Update vehicle information
- Delete vehicle

## File Structure
- main.c → Main menu and program execution
- vehicle.c → All functions implementation
- vehicle.h → Structure and function declarations

## Concepts Used
- Structures
- Arrays
- File handling (if added)
- Modular programming
